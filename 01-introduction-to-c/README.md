# Episode 01 · Introduction to C

*Concepts and History*

C is a language for describing tasks to a computer. It grew out of B and BCPL alongside Unix in the early 1970s, and was standardised as C89 and C90.

**Notes:** [01-introduction-to-c.pdf](01-introduction-to-c.pdf) (colour PDF, A4)

## Key points

- A program is a precise set of instructions; C is one language for writing them.
- BCPL → B → C, and C grew up together with Unix.
- Ritchie created C; Kernighan co-wrote the book (K&R).
- 1989 ANSI C89, 1990 ISO C90. A standard is a shared rulebook, not a guarantee.
