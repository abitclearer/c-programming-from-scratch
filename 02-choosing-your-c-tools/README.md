# Episode 02 · Choosing Your C Tools

*Compilers, Linkers and IDEs*

C source code is plain text, so it must be compiled and linked into an executable before it runs. An IDE wraps those tools in one workspace; this course uses Visual Studio 2026 Community.

**Notes:** [02-choosing-your-c-tools.pdf](02-choosing-your-c-tools.pdf) (colour PDF, A4)

## Key points

- The processor runs binary machine instructions; C source is text, so C is a compiled language.
- Compile turns each .c file into an object file; link joins them with libraries into an .exe.
- A compiler (MSVC, GCC, Clang) is one tool; an IDE is the workspace around it.
- Our setup is Visual Studio 2026 Community with the Desktop development with C++ workload.
