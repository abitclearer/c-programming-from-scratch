## Using the code

The course uses Visual Studio 2026 Community on Windows with the *Desktop development with C++* workload.
Create an empty project, add the `.c` file, then Build Solution (Ctrl+Shift+B) and Start Without Debugging (Ctrl+F5).
Each program ends with an `/* Output: */` comment showing what it prints.
