# Episode 08 · Data Types

*char, int, float and double*

Every value in C has a type. Meet the basic ones for characters, whole numbers and decimals.

**Notes:** [08-data-types.pdf](08-data-types.pdf) (colour PDF, A4)

## Key points

- A type tells the compiler what kind of value it is working with.
- char stores characters written in single quotes; int stores whole numbers.
- float and double store decimals; double usually has a wider range and more significant digits.
- A plain decimal like 3.14 is a double; 3.14f is a float.
